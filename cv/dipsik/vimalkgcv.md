### cpp4-gcc: Custom Compiler for Float-less Computing
- Forked GCC (2.7M line codebase) to create **cpp4** – a C++ variant with **pl8** arbitrary-precision type
- Eliminates float errors and overflow through exact arithmetic
- Modified C/C++ frontends (lexer, parser, type system, builtin type registration)
- Added `RID_PL8` keyword, `pl8_type_node`, and `TI_PL8_TYPE` across GCC infrastructure
- **github.com/zawa8/cpp4-gcc**

### xNglospiik: xNglo India Matrix Text-to-Speech Engine
- Developed advanced **zero-dependency, real-time TTS engine** using Next.js, React, TypeScript, native Web Audio API
- Tokenizes specialized xi38 structural character sequences and maps them to **44 universal linguistic phonemes** (ARPAbet configurations)
- Implemented **mathematical sound synthesis** without external media files:
  - Plosives (K, P, T): exponential energy decay curves
  - Sibilants (S, SH, CH): Gaussian white noise envelopes
  - Vibrato LFO: organic human vocal chord simulation
  - Inflection contours: STEADY, QUESTION, EXCITED emotional modes
  - 25ms linear crossfader: eliminates audible popping
- Deployed on Vercel – responsive on Android, iOS, desktop viewports
